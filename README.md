# Arduino Projects

This repository contains a collection of Arduino-based projects developed to gain practical experience in electronics, embedded systems, sensors, and hardware programming.

# Projects

##Rain Alert System

An Arduino-based rain detection system that uses a rain sensor to detect water and activates a buzzer when rain is detected.

##Digital Timer

A button-controlled countdown timer using an Arduino, 16x2 LCD, and buzzer.

##EMF Based Seismograph 

A vibration detection project using a magnet and coil, LM358 amplifier, Arduino, and LCD to display a simple seismic activity level.
